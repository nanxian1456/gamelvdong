# 律动校园乐队

《律动校园乐队》是一款浏览器单机节奏与乐队经营游戏。你将以四轨键盘挑战三场校园演出，再把获得的经费用于下一阶段的团队经营。

## 开始游玩

预览命令需要 Python 3；运行测试需要 Node.js。项目使用原生 JavaScript ES 模块，没有额外运行时依赖或打包步骤。

在项目根目录运行：

```powershell
python -m http.server 50967 --bind 127.0.0.1
```

然后在浏览器打开 <http://127.0.0.1:50967/>。若端口已被占用，将命令中的 `50967` 换成其他可用端口。

## 游戏内容

- 首页提供独立「新手练习」关：30 秒、11 个音符，分段练习单键点击、四键切换和长按。可跳过或重复，不影响正式赛季与资源。

- 三场演出，每场 32 个音符，节奏速度逐场提高。每首含前奏、主段、合奏和收尾，音乐时长约 38、35、32 秒（另有 3 秒倒数）。
- 音乐由浏览器本地合成旋律、低音、和声与鼓点；谱面与旋律同步，长按对应持续音，不依赖外部音频文件。
- 电脑使用 `D F J K`，依次对应从左到右的四条轨道；手机可点击对应的屏幕按键。
- 音符包含点击和长按两种类型。长按需要持续按住，直至长音符结束。
- 开始赛季前可选轻松、标准或聚光灯难度。难度会影响音符速度、判定窗口、得分和经费倍率。
- 演出间歇可训练、宣传、招募或整理器材；三场结束后可查看最终结果与赛季档案。
- 加练花费 30，经下一场结算固定额外返还 45，不受难度倍率影响。
- 首场开始前有简短教学，演出中保留操作提示；暂停和结算页都能重试本场，重新结算不叠加奖励。
- 设置页可调整声音、音量和动态效果。进度、设置与最近赛季档案保存在当前浏览器的本地存储中，不会在设备间同步。

更完整的操作和判分规则见[玩家玩法说明](docs/玩法说明.md)。

## 开发与验证

项目没有安装步骤、构建脚本或打包流程。启动本地静态服务器后即可预览页面。完整测试运行：

```powershell
node --test
```

`styles.css` 是页面唯一的样式入口，具体规则按职责拆分在 `styles/` 目录中。修改样式前先查看[开发维护指南](docs/开发维护指南.md)中的样式文件地图，避免把新规则追加到不相关的覆盖层。

模块结构、开发规则及文档维护说明见[开发维护指南](docs/开发维护指南.md)。
